🕌 Jadwal Shalat — Lokasi & Sinkronisasi

Sumber data: api.myquran.com (bersumber dari database Bimas Islam Kemenag RI). Kemenag tidak mempublikasikan API resmi untuk publik, sehingga ini adalah sumber terpercaya yang tersedia — granularitas hanya sampai level kabupaten/kota, bukan kecamatan.

Sinkronisasi otomatis harian hanya berjalan jika Administrator sudah menjalankan pasangTriggerSinkronJadwalShalat() sekali dari editor Apps Script (lihat README).
